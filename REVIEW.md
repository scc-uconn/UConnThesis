# Template review — September 27, 2026

This records the initial layout review. The statistics and Rnw revision below
supersedes the original mathematical content and recorded-code examples.
The sample is a teaching template for a doctoral dissertation. It is not yet
ready to be advertised as compliant with every current UConn submission rule.

## Verification

The full PDF was inspected across all pages, with changed layouts and stress
cases inspected again at larger resolution. Clean builds were checked for
LaTeX, package, pdfTeX, BibTeX, overfull, and underfull warnings.

Temporary copies exercised an exactly 350-word abstract in multiple paragraphs,
all seven advisor slots with copyright omitted, and `\includeonly{chap1}`.
All built without warnings. The 350-word abstract occupied two unnumbered pages.
Extracted PDF text coordinates were checked against all four text margins,
including abstract continuation headers and listing numbers. Page numbers were
checked for the suppressed title, consecutive Roman preliminaries, and
consecutive Arabic text, appendix, and reference pages.

The bibliography keys exactly match the citations: no unused entries,
duplicates, string definitions, or old annotations. Chapter packages and shared
commands remain in the preamble. Executable R chunks were deferred during the
initial review; the follow-up below implements them.

## Follow-up: statistics examples and executable R chunks

Replaced the PDE and group-theory material with sampling, estimator bias and
variance, normal-mean likelihood and confidence intervals, and a short appendix
deriving the unbiased sample variance and the bias/variance decomposition of
mean squared error. Basic LaTeX demonstrations remain in Chapter 1.

Chapter 3 includes algorithms for calculating a mean and a percentile bootstrap
interval. A second appendix inputs `Rnw/mean-ci.tex` and `Rnw/bootstrap.tex`, generated by
knitr from the corresponding Rnw files. That folder has its own Makefile and
rendering script; it uses knitr's default LaTeX renderer, with generated setup
loaded from the preamble. The root build regenerates changed chunks, and CI
forces their
execution. Generated tex is provided for direct LaTeX builds without R.

The bibliography now contains only 15 cited entries. Statistical references
replace the former PDE and group-theory references while preserving examples
of every previously demonstrated reference type. Metadata for new references
was checked against publisher or author/institution records.

The numerical normal-mean interval is calculated by an R chunk; bootstrap
resampling uses a fixed seed. The small dataset is explicitly illustrative,
and the displayed bootstrap interval is not presented as evidence of reliable
coverage. The appendix records the R and knitr versions used.

The updated PDF builds without LaTeX or BibTeX warnings. The generated
code and output were checked visually; chunks are single-spaced,
and generated output is included directly through the appendix input.
Regeneration produces identical tex in the
same R environment, changed inputs trigger rebuilding, and an R chunk error
stops Make. These workflow checks ran in a temporary copy.

## Remaining submission gaps

UConn currently requires embedded TrueType fonts. The pdfLaTeX build embeds
Type 1 fonts, so it does **not** meet that requirement. Replacing the font and
engine configuration is still necessary before claiming submission compliance.

The PDF is not tagged. UConn's WCAG 2.1 requirement takes effect for Spring 2027
graduates. Metadata, bookmarks, readable captions, and labeled axes improve the
document but do not establish accessibility compliance; semantic tagging and
an accessibility review remain necessary.

This review covers layout and teaching-source consistency. It does not certify
the historical mathematical results or every inherited bibliographic field.
Windows execution and the remote GitHub Actions job have not been tested in
this review. Master's thesis sequencing is not implemented by changing the
degree name alone.
